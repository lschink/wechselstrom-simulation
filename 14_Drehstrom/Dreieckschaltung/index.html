Strangspannung = Leiterspannung, Leiterstrom = √3 · Strangstrom – der geschlossene Ring ohne Neutralleiter

Einstellungen

Frequenz f
Zum Verfolgen der Kurven zeitdehnt dargestellt – das echte Netz arbeitet mit 50 Hz.
Scheitelwert Û (Strang = Leiter)
Û = 325 V entspricht 230 V Effektivwert. Im Dreieck liegt jeder Strang an der vollen Leiterspannung.
Last pro Strang R (symmetrisch)
Rein ohmische Dreiecklast: jeder Strang (R) liegt zwischen zwei Außenleitern.
Unsymmetrie: R₁₂
R₁₂ ≠ R: Strang- und Leiterströme werden ungleich – ihre Summen bleiben 0, ein Neutralleiter ist nicht nötig.

Betrieb

Start/Stopp friert den Drehwinkel ein; alle Regler wirken sofort auch im Stillstand.

Formeln

uk(t) = Û · sin(ωt − k·120°), k = 1…3
u12 + u23 + u31 = 0  →  kein Ringstrom
i1 = i12 − i31
ILeiter = √3 · IStrang,   ULeiter = UStrang
pges = 3 · UStrang · IStrang = const
